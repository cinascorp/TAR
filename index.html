T∆R

The Airlines Reconstruction

Overview

T∆R is a real-time aerial traffic recognition and tracking system. It ingests live ADS-B / MLAT / FLARM feeds from FlightRadar24, OpenSky Network, and adsb.lol, cross-checks every contact against the military fleet index, classifies it, and renders it on an interactive map with Kalman-filtered dead-reckoning prediction — aircraft move continuously between data updates based on their velocity and heading, not just jumping between fixes.

Kalman Prediction Engine

Each contact runs an independent alpha-beta filter (steady-state Kalman) with the following cycle:

  • Predict (every animation frame, ~60 fps): pos += vel × dt — the aircraft icon advances along its heading at its measured ground speed, producing smooth, continuous motion even between data syncs.
  • Update (on each data sync, ~3 s): the innovation y = measurement − predicted is computed, then position and velocity are corrected: pos += α·y, vel += (β·y)/dt.
  • Jitter entropy: the innovation magnitude (in meters) is recorded into a rolling buffer. After each sync, Shannon entropy H = −Σ pᵢ log₂ pᵢ of the jitter histogram is computed and logged to the browser console, giving a real-time measure of prediction quality and traffic unpredictability.

Altitude Color Spectrum

Each color step represents 1500 meters of altitude (0 – 12,000 m standard band):

  • ■ #666666 Gray — ground level
  • ■ #FFA500 Orange — 0 – 1500 m
  • ■ #FFFF00 Yellow — 1500 – 3000 m
  • ■ #00FF00 Green — 4500 – 6000 m
  • ■ #0000FF Blue — 6000 – 7500 m
  • ■ #4B0082 Indigo — 7500 – 9000 m
  • ■ #800080 Purple — 9000 – 10500 m
  • ■ #FF00FF Fuchsia — 10500 – 12000 m

High-Altitude Contacts (> 30 km): Pink and Cyan for stratospheric / near-space vehicles.

Category Filters

  • Passenger — Scheduled airline flights
  • Commercial — Cargo / charter
  • Private — General aviation
  • Helicopter — Rotorcraft
  • Military — Verified via MIL-SYNC + callsign + serials
  • Fighter — F-15/16/22/35, Typhoon, Rafale, Su-27/35, MiG-29… (pulsing reticle)
  • Mil Transport — C-5/C-17/C-130, A400M, KC-135/10/46, IL-76, AN-124…
  • Bomber — B-1/B-2/B-52/B-21 (flying wing)
  • Drone / UAV — Unmanned aerial vehicles incl. military UAV types
  • Glider — Sailplanes
  • High-Altitude — Contacts above 30 km (Pink/Cyan)

Data Sources

  • FlightRadar24 — data-cloud.flightradar24.com/zones/fcgi/feed.js
  • OpenSky Network — opensky-network.org/api/states/all
  • adsb.lol — community feeders + military hex DB (/v2/mil)

CORS proxies are used as fallback for standalone deployment.

Idx Param Description Unit
0 hex ICAO 24-bit hex identifier hex string

4 alt Barometric altitude feet
5 gs Ground speed knots
6 squawk Transponder squawk code 4-digit
7 radar Radar / source identifier string
8 type ICAO aircraft type code e.g. A332
9 registration Tail number string
10 timestamp Unix timestamp of last update seconds
11 origin Origin airport IATA e.g. MEL
12 destination Destination airport IATA e.g. SIN
13 flight Displayed flight number e.g. QF35
14 vertical_rate Vertical speed ft/min
15 baro_rate Barometric rate number
16 callsign Transmitted callsign e.g. QFA35
17 on_ground Ground flag 0 / 1
18 airline Airline ICAO code e.g. QFA
